TaskPulse 🚀

TaskPulse is a simple and modern Android task management app built using Kotlin.
It helps users stay organized by managing daily tasks, setting priorities, tracking progress, and receiving reminders on time.

The app is designed with a clean UI and follows the MVVM architecture for better scalability and maintainability.

✨ Features

📝 Task Management
Add, edit, update, and delete tasks easily.
Mark tasks as completed or pending.

📂 Task Categories
Organize tasks into categories such as:
Work
Study
Personal

⚡ Priority Levels
Set task priority as:
High
Medium
Low

🔍 Smart Search & Filtering
Search tasks instantly using the search bar.
Filter tasks based on:
Category
Completion status

⏰ Reminders & Notifications
Schedule tasks with deadlines.
Receive reminder notifications using Android system alerts.

💾 Local Data Storage
Uses Room Database to securely store task data locally on the device.
